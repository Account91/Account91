## About

I'm pursuing a DEC in Computer Science in Montreal, with a focus on backend engineering, full-stack development, and infrastructure. I like understanding systems end-to-end — from the database schema up to the reverse proxy in front of it.

Outside of coursework, I build side projects to learn things properly rather than just reading about them: a Unity game to practice game architecture, a self-hosted Docker stack to learn DevOps by actually breaking things.

**Currently:** actively looking for a software engineering internship (35h/week).

## A couple of things I've built

**[1346 – Caffa](https://github.com/amineelghazi)** — A 2D platformer built in Unity (C#), set during the 1346 Black Death. The player is a physician choosing to heal or fight infected animals, with a contamination mechanic tied to combat decisions.

**[tp3-2389824](https://github.com/amineelghazi/tp3-2389824)** — A self-hosted, multi-container infrastructure (Docker Compose) with Traefik as a reverse proxy, automatic HTTPS via Let's Encrypt/DuckDNS, and a full-stack app (MySQL + Node backend + React frontend) running alongside Portainer and Jellyfin.
